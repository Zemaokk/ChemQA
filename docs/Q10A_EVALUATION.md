# Q10-A：固定问题、原文标注与检索基线

工程准备完成；领域人工复核待完成。本轮建立可运行的评估材料，不将 AI 标注或检索命中视为科学结论已经验证。下一项为 Q06.5-B，验证生成模型参数并建立真实生成基线。

## 当前问题与验收

升级前只有运行样例，缺少固定问题、独立预留问题和证据级评分口径。本轮提供 20 个开发题、6 个预留题、原文证据身份与位置、人工评分规则，以及不调用生成接口的检索基线和可回放记录。

- 开发题覆盖事实、条件、机理、数字、体系边界、跨文献比较与有界证据不足；18 题可回答，2 题仅判断指定摘要的信息不足。
- 开发/预留分别来自 11/6 篇论文，按 DOI 分组无交叉；预留题对出题者可见，属于尚未用于开发的候选预留题，不能称为盲测集。
- 26 题共 36 个原文区间已逐字匹配 17 份 PDF；另渲染查看 7 个涉及数值、条件和体系边界的原文页面。逐字匹配证明位置一致，不证明解释正确。
- 所有标注均明确记录 Codex 为起草者，人工作者/复核者为空，领域复核状态为 pending。详见 [开发题复核清单](Q10A_REVIEW.md)。

## 文件与边界

[evaluation/dev.json](../evaluation/dev.json) 保存问题、回答要点、不能声称的内容及证据；[documents.json](../evaluation/documents.json) 保存实际 PDF 标题、DOI、字节身份和来源路径。锚点使用物理页码及原始页文本的半开字符区间，后续改分块仍可对齐，不依赖旧 chunk ID。

[manifest.json](../evaluation/manifest.json) 在首轮运行前冻结题集、来源目录及 [RUBRIC.md](../evaluation/RUBRIC.md) 的哈希。今后修订应创建新版本，保留原结果；不得根据本轮检索表现修改题目后沿用旧基线。预留题只校验来源，命令行禁用其检索和生成。

评分分开记录文献命中、标注文献召回、原文字符覆盖、完整锚点召回、所有锚点完整率、回答要点所需证据完整率和首次命中倒数排名。重复/重叠片段只计区间并集；未定位、错文献、错页码不计覆盖。已标注相关内容并不穷尽所有相关证据，故不报告 precision、nDCG 或全库相关证据 recall。人工回答评分按要点、条件/单位、体系边界、证据支持、引用对应与不足判断分别采用 0/1/2 分，未评审值保持 null。

## 冻结基线结果

当前 26,025 行索引、MiniLM 固定 revision、Top-10、余弦阈值 0.5 均保持原配置。20 个开发查询均在模型的 128-token 输入上限内。使用 CPU 单线程、查询 batch=8，记录模型 revision、题集/索引/查询向量/评估代码哈希及提示版本。原始候选与阈值过滤后的上下文分别评分，本轮两者结果相同。

| 18 道可回答开发题上的指标 | @1 | @5 | @10 |
|---|---:|---:|---:|
| 至少命中一篇标注文献的题目比例 | 38.89% | 61.11% | 77.78% |
| 每题标注文献召回的宏平均 | 36.11% | 58.33% | 72.22% |
| 原文锚点字符覆盖的宏平均 | 0.00% | 5.02% | 10.57% |
| 所有标注锚点完整覆盖的题目比例 | 0.00% | 0.00% | 5.56% |

Top-10 有 14/18 题至少命中一篇标注文献，只有 1/18 题全部标注区间完整覆盖。首次标注文献的平均倒数排名为 0.48025，首次累计完整锚点为 0.00926。这是候选标注上的探索性位置检验，不能解释为回答准确率或检索升级收益。长锚点、非穷尽标签及同文献不同 PDF 身份都影响结果；应先领域复核，再结合错误案例决定后续方案。

[首次基线记录](Q10A_BASELINE.json) 指向独立运行目录，保存查询向量、全部候选与分数、准备但未发送的完整提示、手工评分空模板。[回放记录](Q10A_REPLAY.json) 使用保存的查询向量，验证完整候选/分数/提示、逐题指标和汇总一致。回放新增配置一致性检查，评估代码哈希如实记录；原始运行目录保留，不覆盖。

两道信息不足题不参与正例召回，也没有自动判为正确拒答。生成请求为 0，人工回答质量、token 用量与费用均未测量。下一阶段才建立真实生成结果；正式保留集比较在 Q10-B 候选冻结后执行。

## 使用方法

从项目根目录运行：

```bash
# 仅校验冻结文件与全部 PDF 原文位置；不检索
uv run --locked python -m scripts.validate_q10a
# 只运行开发题检索；输出保存到新的独立目录
uv run --locked python -m scripts.validate_q10a --run-baseline --report output/q10a_latest.json
# 将下列路径换为报告中的 artifact_directory
uv run --locked python -m scripts.validate_q10a --replay output/q10a_baselines/<run-id> --report output/q10a_replay.json
uv run --locked python -m unittest discover -s tests -q
uv run --locked ruff check .
uv run --locked ruff format --check .
```

需要本地原始 PDF、兼容索引及已缓存模型；基线入口强制使用离线模型缓存。无需有效 API 密钥。输出默认位于被忽略的 output 目录；源码导出现在包含 evaluation 文本材料，仍不包含 PDF、向量、模型、密钥或历史。

验证记录见 [Q10A_VALIDATION.json](Q10A_VALIDATION.json)。现有索引与处理后语料哈希保持不变；这轮没有改模型、分块、索引或阈值。
