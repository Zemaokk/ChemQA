## 当前问题、影响与验收

Q10-B 助手评审记录显示：生成可能自行补全抽取损坏的反应式，将不同优化阶段的条件并列为最终性能工况，或将检索片段未见证据扩大成全文没有对照。本项验收限定为新合成案例上的行为约束、失败隔离、预算/溯源和旧实验不变；不把已消费预留题重新用于独立测试。

## 实现

- 新策略 `chemqa-conservative-answer-r01-v1` 只回答所问指标，逐项说明数值对应的实验阶段与工况；无法确认绑定时明确保留不确定性。
- 不主动扩展带电反应式；明确询问时只接受同段引用片段逐字保留的式子。符号疑似损坏时提示回查 PDF，不依常识补全。
- 针对可识别单位，检查所问指标范围以及同段引用中是否有对应带符号数值/单位；电流与电流密度分开。负效率/选择性须明确提示异常，不能仅写“原文如此”。
- 阻止部分全文缺证据绝对断言及不可解析引用。检查发生在生成返回后；触发时保存 `failure.json`，保留原始回答、usage、响应 ID 和具体 findings，不产生正常 `answer.md`，不因检查失败自动重试。
- `ChemicalQAExpert`（命令行及问答批量入口）默认安装新生成器。历史 `DeepSeekAnswerGenerator` 与原提示保留供旧评估重放；直接使用旧类或独立 API 批量脚本不受新检查保护。
- 提示版本和实际提示哈希进入输入记录；候选完整请求预算包含新提示，发送前继续核查。新增提示可能改变实际入选片段，不能当作 Q10-B 原生成配置。

## 验证与限制

18 项新合成测试覆盖数值正负号、中文紧邻数字、引用段落、单位/密度、未询问指标、公式电荷、异常百分比、局部缺证据说明、失败落盘、旧提示绕过、空证据和完整请求预算。完整检查见 [验收记录](R01_VALIDATION.json)。没有发送新 API 请求、重排预留题、改写旧评分或重建索引。

`passed_lexical_checks` 仅表示通过有限的词法检查，记录始终含 `scientific_support_verified: false`。相同数字出现在同段引用，并不能证明它属于该项性能；工况绑定主要由提示约束，尚未实现语义证明。单位/表达覆盖有限，可能漏检或误拦；逐字相同的反应式仍可能已在 PDF 抽取时损坏，无法验证电荷守恒或原页正确性。本轮不宣称准确率提高、幻觉消除或科研结论已验收。
