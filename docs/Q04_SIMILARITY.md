# Q04：统一检索与热力图的余弦评分

## 问题与选择

此前检索使用未归一化点积，热力图重新编码各片段后计算余弦相似度。两个分数口径不同：例如查询 `[2, 0]`，片段 A 为 `[1, 0]`、B 为 `[10, 10]`，点积把 B 排在 A 前面，而余弦分别为 1 和约 0.707。片段向量的长度可能改变点积排名，不能将此前检索分数直接理解成热力图上的余弦分数。

本次统一采用余弦相似度：查询与片段分别按 L2 范数归一化后比较方向，分数范围为 `[-1, 1]`。相同方向为 1，正交为 0，反向为 -1；它不是概率，也不是证据可靠性的置信度。

## 实现

- `similarity.cosine_scores` 提供共用数学实现；输入转为 float64，先按最大绝对值缩放再归一化，避免极大/极小有限数值引起上溢或下溢。零向量、非有限数值或维度不一致明确报错。
- `VectorStore.score_query` 只编码查询，对已有索引向量计算全部片段的余弦分数；`similarity_search` 和热力图数据准备都调用此入口。
- 不重编码文献、不修改持久化向量、不改变片段文本与身份，不需要重建 Q03 索引。现有全量及增量索引产生的非单位向量均在评分时归一化。
- 排序按余弦分数降序；分数相同时保留索引行顺序。请求数量超过行数时返回已有行；0 返回空结果，不编码查询；负数或非整数拒绝。
- 单查询热力图的选中片段和排序与同一查询的检索一致。多查询热力图仍按**各查询余弦分数的平均值**选择展示行，不能把这个综合排名当成某一个查询的 Top K。
- 热力图直接复用索引向量，每个查询仅编码一次，不再对所有片段逐一重复编码。默认颜色范围使用 `[-1, 1]`，注释显示实际分数；行数少于 `max_docs` 时按实际行数生成标签，打印完整 `chunk_id`、来源及物理页码对应关系。
- `Retriever.min_score` 明确为余弦阈值，并检查有限数值及 `[-1, 1]` 范围。继续保留默认值 **0.5**，该值没有经过标注集校准；现在的筛选结果可能不同于此前点积阈值，需在后续评估中确定是否合适。

新增 9 项 Q04 回归测试，连同 Q01–Q03 共 **41 项**。覆盖点积/余弦排名反例、正比例缩放不变性、检索与热力图分数及身份一致、跨查询均值选行、同分排序、数量边界、零/非有限向量、维度错误、阈值过滤及真实图像渲染。

真实验收使用 Q03 的 **26,025 × 384** 索引及原热力图的 5 个示例查询：将共享评分逐条与独立余弦公式比较，再核对检索 Top 10、单查询热力图排名与多查询均值选行。只调用查询编码，文献编码次数为 0；校验前后比较两份数据文件的 SHA-256，确认没有改写。具体差异、向量范数范围、每个查询的分数与相对旧点积 Top 10 的交集见 [Q04_VALIDATION.json](Q04_VALIDATION.json)。示例图保存在被忽略的 `output/q04_similarity_heatmap.png`。

本次实测共用评分与独立公式的最大差异为 **4.44×10⁻¹⁶**。文献向量 L2 范数最小/中位数/最大值约为 **2.247 / 3.176 / 6.161**，确认存储向量并非单位向量。5 个示例查询中，余弦与旧点积 Top 10 的交集数量依次为 **4、5、2、1、2**；验收及渲染累计调用查询编码 21 次，文献编码 0 次，数据文件哈希保持与 Q03 验收一致。

这是评分一致性验收，示例查询没有相关性标签。排名发生变化不代表检索或回答质量提升，也没有调整证据不足时的回答行为、提示结构或 API 状态处理；这些仍按后续事项推进。
