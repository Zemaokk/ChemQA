# Q06：证据不足与跨体系回答边界

## 当前问题及本项边界

Q05 已统一输入与引用身份，但原提示要求详细解释机理、讨论工业应用和优化方向，可能诱导模型在材料不足时补全内容。空检索也会调用 API；格式化页面还使用“综合了研究文献的见解”，容易把取回材料与获得科学支持混为一谈。

本项分别处理可以确定的空证据与尚需语义判断的非空证据：空证据由代码停止生成；非空证据通过明确提示约束体系与主张的适用性，不假装用关键词或引用数量判定科学充分性。

## 实现与验收标准

### 空证据：确定性停止

- 生成器验证问题及上下文后，如果规范化片段列表为空，返回固定的中文说明，**不调用 API**。`None`、空列表及对应的准备好输入走同一条路径。
- 明确说明“当前检索证据不足”，不生成机理、性能数值、最优条件或应用前景，不使用其他体系类比补结论。
- 区分“没有取回证据”“相关文献不存在”和“主张已被反证”，只陈述第一种情况。
- 用户强迫猜测或自定义模板要求忽略证据，也不能绕过空证据门控。问题、身份或模板错误仍报错，不冒充证据不足。
- 保存正常的 Markdown 与证据 JSON，证据映射为空、没有编造引用；准备的提示仍可审计，但 `prompt_sent: false` 明确说明未发送。

### 非空证据：提示边界与诚实记录

提示升级为 `chemqa-evidence-boundary-prompt-v2`，要求先核对用户体系及所问主张，再区分直接支持、部分支持与当前证据不足：

- 核对反应物/目标产物、催化剂、电解液、反应器构型、电位基准、操作条件及指标。缺少条件明确标为未说明。
- 其他反应、催化剂或反应器的观察仅作为背景，不能直接推成目标体系的机理、性能或最优条件；缺少可比条件时不排序。
- 区分观测、作者解释与假设；相关性不等于机制或因果证明，未报告不等于无效或不存在。
- 仅报告被支持的部分。没有直接证据时不为凑章节而扩写；移除原来无条件要求解释机理、讨论工业应用的提示。
- 用户明确要求类比或假设时，可以说明背景来源、体系差异与检验办法，但必须标为待验证假设，不能表述成目标体系的既定事实。
- Q05 的证据 JSON 与完整 ID 引用约定继续使用。

这部分是**对模型的提示要求**，没有自动验证每个主张的科学支持，也没有一个经过评估的语义判别器。非空检索的决策记录始终为 `retrieved_not_assessed`，`scientific_support_verified: false`，不能把它当成“证据充分”。

## 输出记录

`generation_input` 新增：

- `prompt_sent`：实际是否走模型请求路径。空证据为 false，保存的是准备但未发送的提示；非空为 true。
- `decision.policy_version`：`chemqa-evidence-boundary-v1`。
- `decision.evidence_availability`：`none` 或 `retrieved_not_assessed`。
- `decision.route`：`local_no_evidence` 或 `model_request`。
- `decision.scientific_support_verified`：当前均为 false。

这些是证据门控记录，不是 API 成功状态。现有 API 错误字符串处理仍属于 Q07，未在本项改写。

格式化页面将“综合了研究文献的见解”改为实际检索的文献/片段数量，并说明检索命中与引用定位不代表支持全部结论。空证据页面明确显示本次未取回符合筛选条件的片段。

新增 9 项 Q06 回归测试，连同 Q01–Q05 共 **60 项**。覆盖所有空输入入口、强迫猜测/模板绕过、错误输入不误判、保存的未发送状态、非空记录不冒充科学验证、API 异常传播、体系核查提示、跨体系背景与显式假设要求。

另保存了 8 个**人工构造的合成样例**，涵盖空证据、强制推断、同体系直接结果、缺少指标、不同反应、不同构型、不可比排序及明确要求假设。例文中的数据是测试虚构，不能用于科学结论。`expected_boundary` 是后续真实模型评估用的预期注释，不是程序自动得到的语义判断。

离线脚本验证：2 个空证据样例均本地停止，HTTP 调用为 0；6 个非空样例使用模拟 HTTP，核对边界指令进入实际请求、提示与保存快照一致、科学支持状态保持未核实。所有外部 API 请求均为 **0**，索引与片段文件 SHA-256 不变。详细记录见 [Q06_VALIDATION.json](Q06_VALIDATION.json)。

## 仍需完成的模型行为评估

当前没有配置 API 密钥，未运行真实 DeepSeek 回答评估。**非空证据下能否稳定拒绝错误跨体系外推尚未验证**，不能把模拟响应或提示文本检查当成模型遵守证据边界的证明。

后续应使用这些样例及有来源、有人审核的真实文献问题，重复测试拒绝越界、局部回答、假设标签和事实/引用支持，并记录违反边界的案例。即便引用合法，事实性主张仍需逐项核查。相关受控质量评估按 Q10 继续推进；本项不声称问答质量提升。
