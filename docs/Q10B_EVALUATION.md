| 方案 | 输入/选择 |
| --- | --- |
| Direct | 无外部检索，问题与明确的不确定性指导；不允许虚构文献引用 |
| BM25 | F 相同文献片段上的 G BM25 前50候选 |
| Dense | F 的 Qwen embedding 精确余弦前50候选 |
| Hybrid + reranker | G 固定 RRF 前50，采用 H 固定 Qwen 重排 |

四个 RAG 方案使用同一 Q05/Q06 证据与体系边界提示。公共选择规则最多10个完整片段、相同完整请求字节预算及文本去重；公共每篇上限为10、来源跨度阈值为1，不额外施加 I 的单篇/重叠限制。I 对照严格沿用已冻结的每篇6/跨度0.5策略，未根据 D08 或预留结果调参。

## 引用统计修正

旧 `citation_coverage` 实际是“引用过的上下文片段数/上下文片段总数”，不是主张覆盖或科学支持率。本轮保留该字段兼容旧消费者，显示文字改为“上下文片段使用率”，增加明确的结构统计：

- `marker_resolution_rate`：已映射标记出现次数/全部捕获标记出现次数；重复引用逐次计数，数字旧引用在新答案中计无法映射。
- `context_chunk_utilization`：被引用的不同片段数/提供的不同片段数。
- `context_document_utilization`：被引用的不同文献数/提供的不同文献数。

没有标记或没有上下文的相应分母为0时返回 null，不能算作100%或科学成功。不匹配所支持事实的合法ID仍能结构映射，所以 `claim_support_precision` 和 `claim_citation_recall` 保持 null，等待全体主张及所引原文人工标注。

[旧 B 重算](Q10B_BASELINE_CITATIONS.json) 只使用每个历史答案原始冻结证据，先逐字核对 B 的输入快照，没有拿新 H/I 上下文重新解释旧引用，也没有覆盖原始结果。
