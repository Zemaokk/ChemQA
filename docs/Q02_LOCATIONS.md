# Q02：PDF 页码与原文位置

日期：2026-10-06

状态：位置记录与核查流程已完成。旧数据中 3,123 个片段已定位，64 个片段明确未定位；没有补写推测页码。

## 问题与验收标准

Q01 已能识别文献和片段，但原 PDF 提取把各页文本直接拼接，丢失了页边界。稳定片段 ID 因而不能直接告诉使用者应查看 PDF 哪一页、哪段提取原文。

本项验收：

1. 页码采用从 1 开始的 PDF 物理页序号，空白页也占一个页号。
2. 每个片段记录所有涉及的页面，以及页内字符区间和未经 ChemQA 清洗的原文提取片段；跨页片段保留多段位置。
3. 页面记录可随分块、索引、检索、引用分析与回答证据 JSON 保留，Markdown 输出显示页码和原文预览。
4. 新位置记录保持旧清洗及单词分块行为；旧数据迁移不改变文本、doc_id、chunk_id、行顺序和向量值。
5. 无法逐字核验的位置明确标为不可用；再次迁移不写入文件。
6. 独立重新打开 PDF，验证每一个已记录字符区间都能取回相同的原文提取片段。

## 位置定义

- `location_version`：`pymupdf-text-offset-v1`。
- `location_status`：`located` 或 `unavailable`；不可用时提供 `location_reason`，页码及片段数组为空。
- `location_extractor`：提取库、版本和方法；本次实测为 PyMuPDF 1.28.2 的 `get_text(text, sort=False)`。
- `page_numbers`：实际提供证据文本的 PDF 物理页序号。跨越空白页时可以为 `[1, 3]`，不把空白的第 2 页列为证据页。
- `source_spans`：每项包括 `page_number`、`char_start`、`char_end` 和 `raw_text`。区间为页内 Python Unicode 字符位置 `[start, end)`，相对于该页 `get_text` 返回的字符串。

这里不是 PDF 文件字节偏移、论文印刷页码、页面坐标或高亮框。`raw_text` 是未经过 ChemQA 清洗的 PDF 提取文本，不保证提取器已完整还原原稿的字符、公式或阅读顺序。验证证明的是提取文本与记录对应，不能替代对页面图像的核查。

## 实现与边界

- PDFLoader 同一次读入的 PDF 字节用于身份哈希和逐页提取；保存页文本、累积边界、物理页号与提取器版本，并在完成提取后关闭 PDF。
- `location.py` 为现有空白归并及符号清理保留字符对应关系，再沿用原有单词数和重叠规则生成位置。
- 片段边缘保留原 token 中被清理规则删除的符号。例如索引文本可能仍为 `Ni2`，原文提取片段可以保留 `(Ni2+)`。这不是对 Q03 清洗问题的修复，模型当前仍接收旧的清洗文本。
- 同一文献的各页仍按旧规则直接拼接；没有额外插入分隔符，因而不改变既有文本和片段身份。没有空白的跨页接续词也按旧行为处理。
- 重复导入可补入之前缺少的已核验位置，不重新编码向量；已有位置不会被缺失位置覆盖，同一 ID 的冲突位置会报错。
- 检索返回完整位置元数据；分析器和 Markdown 显示物理页码。Markdown 对每个页片段提供至多 200 字符的原文预览，完整文本与字符区间保存在 `.evidence.json`。

## 旧数据迁移

`scripts/migrate_q02.py` 默认只读预览，`--apply` 先备份两份原文件，再补入位置元数据。

迁移重新读取当前 PDF 并核对 doc_id，按当前清洗和分块规则重放；只有对应局部片段的文本逐字等于原记录时才记录位置。不同 PDF 字节、缺少匹配来源或提取文本不一致，都不产生推测位置。

| 项目 | 结果 |
|---|---|
| 保留片段和向量行数 | 3,187 |
| 已定位片段 | 3,123 |
| 其中跨页片段 | 1,746 |
| 页内原文区间 | 5,005 |
| 未定位片段 | 64，分布于 5 份 PDF |
| 核查的不同 PDF 字节内容 | 180 |
| 原片段文本、身份及向量值 | 与 Q01 基线完全一致 |
| 再次应用迁移 | 不写入文件 |

64 个未定位片段的原因是对应旧片段与当前提取和分块重放结果不一致。本项没有认定不一致由哪一个具体版本或处理步骤造成，也没有覆盖旧文本或重新编码。涉及的来源及完整 SHA-256 见 [Q02_VALIDATION.json](Q02_VALIDATION.json)。后续需单独分析提取差异，再在 Q03/Q08 的处理与重建工作中决定如何处理。

原文件备份位于被 Git 忽略的 `output/q02_backups/`。备份文件名含原 SHA-256；备份不随 Git 分享。两份 JSON 分别以临时文件替换，不宣称跨文件事务。

## 验证与复现

```bash
# 默认只读预览；加 --apply 才备份并补位置
uv run --locked python -m scripts.migrate_q02

# 独立重新打开 PDF，核查所有已定位记录
uv run --locked python -m scripts.validate_q02

# 对照 Q02 迁移前的备份，还可验证文本、身份和向量没有变化
uv run --locked python -m scripts.validate_q02 --baseline-index /absolute/path/to/vector_index.<sha256>.json

uv run --locked python -m unittest discover -s tests -v
uv run --locked ruff check .
uv run --locked ruff format --check .
HF_HUB_OFFLINE=1 uv run --locked python -m scripts.smoke_check --retrieval
```
