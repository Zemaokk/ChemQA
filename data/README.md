# Local literature and indexes

This directory is not bundled with a source checkout. Only this guide is tracked.

| Directory | Contents |
| --- | --- |
| `raw_papers/` | Original PDFs you are permitted to process. |
| `processed/` | Extracted chunks, source locations, and metadata. |
| `vector_db/` | Compatibility-default JSON index. |

[Build your own index](../docs/how-to/build-index.md) or follow [the first-question tutorial](../docs/tutorials/first-question.md). Replaying the original experiments requires matching PDFs, indexes, model caches, and run artifacts, verified against their manifests. Keep a separate permitted backup.
