# Changelog

Notable changes to ChemQA are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

This changelog starts with the documentation migration. Earlier experiments remain in their dated records; no historical release dates or tags have been reconstructed. Package metadata currently declares 0.1.0. A release-versioning policy has not yet been established.

## Unreleased

### Added

- Documentation navigation by tutorial, how-to, reference, and explanation.
- Architecture decision records with a proposal template and lifecycle guidance.
- A current summary of Q10-B and P3 results, including publication-check rejection and delivered-answer limits.
- Documentation migration map and a local link/archive verification utility.
- A contribution guide and this curated changelog in source snapshots.

### Changed

- Replaced chronological working notes as the main documentation with task-focused English guides and interface contracts.
- Updated README and data-directory navigation to the new documentation.
- Redirected generated experiment scope notes to local outputs so historical tools do not recreate retired guide paths.

### Removed

- Old prose guides, plans, batch README, and authored PDF report from the active source tree; preserved their original bytes in the Git-ignored local `legacy-docs/2026-10-09/` archive.
