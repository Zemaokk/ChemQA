# P3 v1 评分规则（生成前冻结）

适用范围：30道论文特定问题、20个文章组、两种完整系统配置。标准依据questions.json的answer_points/evidence/must_not_claim，不因为生成结果好坏修改标准。

- 每必要要点0/1，只有完整、准确、单位/参比/条件对应正确才记1；部分、遗漏、错误为0。若额外主张直接否定某必要要点，该点记0。
- `major_errors` 逐条记录有原文依据的重大事实错误或工况错配；出现至少一个，`penalized_score = min(mean(point_correct), 0.5)`。没有则等于严格要点正确比例。较轻文字问题只备注。不能为了保证提升选择性忽略额外错误。
- 失败、空回答、截断的主分析要点均为0；另列技术状态。不把拒答从分母移除。
- 将回答中的可核查原子事实主张拆分为claims；每条含text、citation_markers、support_label、reason、source_refs。带引用主张只有所引输入原文完整支持才标supported；partial/unsupported/unverifiable都不计支持。无引用主张标uncited，支持率分母不含它，但事实引用覆盖率分母包含。不能用“引用ID可解析”代替支持判断。非事实的建议/拒答说明不强制计为事实主张。
- 同一主张多个引用仍计1条；引用支持只检查该主张明确所引原文。Direct没有外部文献支持维度（NA），其虚构引用另计重大错误。
- 评分需记录reviewer_id、reviewer_kind、每要点reason和证据页码。AI起草与评审必须标明；未评分不得生成科学质量结论。用户复核应追加review_notes与裁决身份，不静默覆盖初始评分。
- 先每题平均3次，再按文章组平均，最后文章组宏平均。两方案配对文章组bootstrap10,000次，固定种子20261008，报告百分点差和95%区间。独立聚类数20；不把重复请求当独立样本。置信区间仅反映这批抽样，不消除选题、助手评审或模型别名漂移偏差。
- 同时报告原始要点、惩罚后要点、重大错误率、技术失败/截断率、RAG原子引用支持/覆盖、发布拦截率与失败/拦截记0的交付分。不能只展示拦截后幸存回答的支持率。
